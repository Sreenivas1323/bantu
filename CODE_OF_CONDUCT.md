# Code of Conduct

Bantu follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussion about the work.
Harassment of any kind is not tolerated.

Report problems privately to the maintainers through [GitHub private vulnerability reporting](https://github.com/Sreenivas1323/bantu/security/advisories/new) or by contacting [@Sreenivas1323](https://github.com/Sreenivas1323) on GitHub.
Reports are kept confidential.
